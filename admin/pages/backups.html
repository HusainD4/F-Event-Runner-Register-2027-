Backup Database

Unduh seluruh tabel InnoDB dan datanya dalam satu snapshot konsisten. Akses hanya tersedia untuk Superadmin.

File backup berisi data sangat sensitif.

Termasuk data peserta, konfigurasi, dan hash password admin. Simpan di tempat terenkripsi dan jangan bagikan file secara publik.

Backup SQL lengkap

Skema dan data tabel untuk pemulihan. Impor ke database kosong; uji hasil pemulihan sebelum dibutuhkan.

Backup CSV gabungan

Data semua tabel untuk pemeriksaan; kolom table_name membedakan jenis record. CSV bukan format pemulihan database.

Backup tidak mencakup view, trigger, prosedur, event MySQL, file gambar, Redis, konfigurasi server, atau transaksi pada Midtrans. Jangan mengubah skema database selama backup. Simpan file dengan aman.
